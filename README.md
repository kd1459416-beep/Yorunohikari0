# ヨルノヒカリ

夜中の授乳や夜泣き対応における「精神的孤立感」を、他の利用者の気配のリアルタイムな可視化と、匿名コミュニケーションによって和らげる、夜間特化型の育児サポートアプリです。

神戸電子専門学校 AIシステム開発学科 個人開発プロジェクト（開発: 花房舞央）

---

## 概要

- **ターゲット**：乳幼児を養育中の保護者（主に夜間の授乳・夜泣き対応を行う母親・父親）
- **コンセプト**：深夜の「精神的孤立感」を、①会話のコストをかけずに得られる「緩やかな繋がり」と、②気を遣わず深夜でも頼れる「心理的安全性」の2つで和らげる

夜間育児に関する調査（株式会社カラダノート, 2024年, N=700）では、52.7%の保護者が夜間育児に孤独を感じたことがあると回答しています。周囲のサポートを得にくい環境や、初めての育児ではこの傾向がより強く出ます。

## 開発の経緯

当初は赤ちゃんの嚥下音を解析し哺乳量を可視化する技術に取り組んでいましたが、助産師・保育士・子育て中の保護者へのヒアリングを重ねる中で、技術面・実用面の両方で大きな壁があることが分かり方向転換しました。そのヒアリングの過程で見えてきたのが「夜間育児の孤独感」という、より本質的な課題です。本アプリはこの課題に向き合うために開発しています。

## 主な機能

| 機能 | 内容 |
| :--- | :--- |
| 🌙 他者の存在の可視化 | 「授乳対応中」「寝かしつけ中」ボタンを押すと、地図上に自分の灯りが点灯し、現在対応中の人数がリアルタイムに分かる。位置は登録した地域からランダムに±約2.5kmずらして表示するため、自宅が特定されることはない |
| 📊 授乳・夜泣き記録 | 授乳の種類・量・様子や、寝かしつけにかかった時間を記録。前回の授乳時刻や時間帯別の傾向をグラフで確認できる |
| 💬 2つのチャット | 完全匿名で育児の悩みを共有できる「リアルママ広場」と、Gemini APIを使った「AIママ相談室」。AIはアドバイスの前にまず気持ちを受け止めるよう設計している |
| 🎵 ヒーリング音楽 | 夜泣きの緩和・寝かしつけをサポートする音源を再生。アプリに内蔵しているため通信不要・オフラインでも再生できる |

## 技術スタック

| レイヤー | 技術 | 役割 |
| :--- | :--- | :--- |
| フロントエンド | Flutter / Dart | iOS・Androidを1つのコードベースで開発 |
| 地図 | flutter_map, latlong2, OpenStreetMap / Esri タイル | 地図の描画と座標計算（タイル画像の配信元を借りているのみで、契約やAPIキーは不要） |
| AI | Gemini API（google_generative_ai） | AIママ相談室の応答生成。`gemini-3.5-flash-lite`を優先利用し、混雑時は`gemini-3.8-flash`へ自動フォールバックする2段構え |
| 認証 | Firebase Authentication | メール/パスワードに加え、匿名ログインにも対応 |
| データベース | Cloud Firestore | 灯りの状態・記録・チャット投稿をリアルタイムに同期 |
| 通知 | flutter_local_notifications, timezone | 授乳リマインダーを端末のローカル通知で予約 |
| その他 | audioplayers, fl_chart, shared_preferences, flutter_dotenv, geocoding | BGM再生、グラフ描画、端末内設定保存、APIキーの環境変数管理、住所から座標への変換 |

## 開発上の工夫

1. **プライバシーに配慮した可視化**：位置情報はGPSではなく、登録した地域の座標をもとに算出し、さらにランダムに±約2.5kmずらしてから地図に表示。自宅や現在地が特定されない設計にしている。
2. **深夜でも固まらない通信設計**：記録や灯りの書き込みは、保存の完了を待たずに画面へ即時反映。Firestoreの端末キャッシュにより、電波が弱い状況でも操作が止まらない。
3. **AIの失敗に強い設計**：Gemini APIが混雑・タイムアウト・設定ミスなどで失敗した場合、原因ごとに異なる分かりやすい日本語メッセージを表示し、必要に応じて別モデルへ自動的に切り替える。
4. **最低限のモデレーション**：匿名掲示板への投稿・コメントには、暴言や連絡先交換を検知するNGワードフィルタを設置。複数人から通報された投稿は自動的に非表示になる。

## セットアップ手順

### 必須要件

- Flutter SDK（`^3.12.2`以上）
- Firebaseプロジェクト（Authentication・Cloud Firestoreを有効化したもの）
- Gemini APIキー

### 手順

```bash
# 1. リポジトリをクローン
git clone https://github.com/kd1459416-beep/Yorunohikari0.git
cd Yorunohikari0

# 2. パッケージを取得
flutter pub get

# 3. Gemini APIキーを設定（プロジェクト直下に .env を作成）
echo "GEMINI_API_KEY=your_api_key_here" > .env

# 4. Firebaseの設定ファイルを配置
#    - android/app/google-services.json
#    - ios/Runner/GoogleService-Info.plist
#    - macos/Runner/GoogleService-Info.plist
#    （Firebase Consoleでアプリを登録し、ダウンロードしたものに差し替える）

# 5. 実行
flutter run
```
