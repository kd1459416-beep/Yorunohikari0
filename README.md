# ヨルノヒカリ

夜中の授乳や夜泣き対応における「精神的孤立感」を、リアルタイムな気配の可視化と匿名コミュニケーションによって緩和する、夜間特化型育児サポートアプリです。

---

## 概要
- ターゲット: 乳幼児を養育中の保護者（主に夜間授乳・夜泣き対応を行う母親・父親）
「夜中に一人で育児に悩み、不安になるお母さんたちの心に寄り添う」ことを目指して開発したアプリです。

- コンセプト: 深夜の「精神的孤立感」を、リアルタイムな気配の可視化と匿名コミュニケーションで緩和する

---

## 開発背景 
母の勤務先に来られる育児中のママや保育士の方々に育児における困りごとについて実際にヒアリングを行った際、「夜間育児における強い孤独感」が課題であることが分かりました。
周囲が寝静まった深夜に一人で授乳や夜泣きに向き合う日々が続くと、「社会から自分だけが孤立してしまった」ような感覚に陥ってしまいます。
こうした現場の生の声をきっかけに、「夜間の孤独感を少しでも軽減し、深夜に一人で頑張るママたちが『自分は一人じゃない』と安心できる場所を作りたい」と考え、本アプリの開発に至りました。

---

## 主な機能 

### 1. 可視化・気配の共有（コア機能）
- 🌟 日本地図の灯火表示
 - ユーザーが任意で設定した現在地（都道府県単位）に光のピンを立て、同時接続人数をリアルタイム表示。「今、同じように夜間育児を頑張っている仲間」の存在を可視化します。
- 📅 記録・履歴管理 
 - 授乳時間、赤ちゃんが就寝するまでの経過時間を計測し、記録します。
- 👩 リアルタイム掲示板
 - 深夜特有の感情を吐き出せる匿名チャット。
- 🤖 AIママ チャット機能
  - Gemini API (`gemini-3.8-flash`) を活用したストリーミング対話
  - 優しい口調で寄り添うプロンプト設計
- 🎵 BGM / ヒーリング機能
  - 心を落ち着かせる音声再生機能

## 開発上の工夫・こだわった点 (Engineering Highlights)

1. 「孤独感の解消」にフォーカスしたプロダクト設計
   - 単なる AI チャットにとどまらず、夜泣き対応中の他のユーザーを可視化することで、「自分だけじゃない」と思えるメンタルケア体験を追求しました。

2. プライバシー & 完全匿名性
   - 位置情報は都道府県レベルにとどめ、詳細なGPSデータは保持・表示しません。

3. ストリーミング応答と環境変数の安全管理
   - 生成 AI の応答を待たせないストリーミング処理（`generateContentStream`）を実装。
   - API キーは `.env` および `--dart-define`（ビルド時注入）で安全に分離・管理。

## セットアップ手順 (Getting Started)

### 必須要件
- Flutter SDK
- Firebase プロジェクトの設定 (`firebase_options.dart`)
- Gemini API Key (`GEMINI_API_KEY`)

```bash

# 2. フォルダへ移動
